列出目录的递归树。

参数：

- `path`（可选）：目录路径，默认为当前工作目录。
- `all`（可选，布尔）：为 `true` 时忽略 `.gitignore`/`.git` 全局与本地排除规则，并列出隐藏
  （以 `.` 开头的）条目；默认 `false`，即遵守 `.gitignore`。

递归深度最多 5 层，总条目数最多 100 条；超出会在输出末尾标注截断。目录条目名后缀 `/`。
符号链接会探测目标类型来决定是否带 `/` 后缀，但不会跟随其递归展开（防止链接成环）。

需要单个文件的内容请改用 `read` 工具；`read` 指向目录时也会给出一份更浅的摘要，但完整树请用
本工具。
