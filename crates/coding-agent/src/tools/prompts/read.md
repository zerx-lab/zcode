读取文件或目录内容。

`path` 是唯一参数：本地路径，可选带一个冒号选择器后缀控制分页与显示模式。

- `path/to/file` —— 从头读，使用配置的默认页大小（受硬顶 3000 行 / 50 000 字节约束）。
- `path:N` —— 从第 N 行开始读（1 起始），沿用默认页大小。
- `path:N-M` —— 读第 N 到第 M 行（含两端）。
- `path:N+K` —— 从第 N 行开始读 K 行。
- `path:N-` —— 从第 N 行读到文件末尾（受硬顶约束）。
- `path:5-16,960-973` —— 逗号分隔的多段区间，一次返回多个不连续片段。
- `path:raw` —— 逐字节透传，不加行号前缀，不补上下文行。
- `path:raw:N-M` 或 `path:N-M:raw` —— 指定区间 + 逐字节透传（两种顺序等价）。

选择器语法之外的整段路径若在磁盘上确有其名（例如文件名恰好叫 `test:1-2`），按字面文件名处理，
选择器解释让路。

单个显式区间会自动补少量上下文：起点之前补 1 行、终点之后补 3 行（`:raw` 与逗号多段都不补，
避免和请求内容混淆）。行号越界时会给出可操作的下一步建议，而不是空报错。输出末尾若还有更多行，
会附上 `[还有 N 行。用 :<next> 继续]` 提示，下一次调用照抄即可。

`path` 指向目录时返回浅层摘要（深度 2、每目录最多 12 条），需要完整目录树请改用 `ls` 工具。

`path` 指向受支持格式（PNG/JPEG/GIF/WebP）的图片时，会解码并按需缩放后作为图片内容返回；
无法识别的其它二进制文件会报错并说明原因。
